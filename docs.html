InnerNet Docs

InnerNet is a private web inside the web. You can register domains, host pages, send in-mail, and build apps — all powered by LUCKS, InnerNet's internal currency.

The backend runs at own-net.vercel.app. The browser is at innernet.qzz.io or innernet.lbc. Everything else lives on top of these two.

InnerNet is not the real internet. Domains like .lbc only resolve inside the InnerNet browser. Links shared outside won't work unless the viewer also uses InnerNet.

TLDs & Pricing

All domains cost 100 LUCKS flat. No renewals, no auctions.

TLDRules
.lbcGeneral purpose. No restrictions.
.greenGeneral purpose. No restrictions.
.partyGeneral purpose. No restrictions.
.ccGeneral purpose. No restrictions.
.innMust contain content exclusive to InnerNet.
.abcGeneral purpose. No restrictions.

Single-letter domains are valid. No length limit. Standard DNS character rules apply: lowercase letters, numbers, hyphens in the middle only.

Register a Domain

Go to getaname.lbc and search for any name with a TLD. If it's available, click Register. The 100 LUCKS are deducted immediately.

After registering you can set two DNS records from the domain panel:

RecordPurpose
CNAMEPoints the domain to a page. Can be an upload URL, a project URL, or any external URL.
MXSets the mail server. Use mail.host to enable in-mail for this domain.

getaname.lbc

The domain registrar. Search, register, and manage all your domains from one place. Available at getaname.lbc and also at innernet.qzz.io/dns.

Features

Search any name with or without TLD. Exact matches show availability instantly. Set CNAME and MX records per domain. View your full domain list under "My Domains".

host.lbc

Upload HTML pages and host them on InnerNet. Supports drag & drop, a built-in code editor, and live preview.

Upload flow

Write or paste your HTML → click Upload → get a public URL at own-net.vercel.app/upload/UUID. Then link it to a domain by setting that URL as the CNAME.

Single uploads are one-file only. For multi-file sites with CSS, JS, and images use Projects instead.

mail.party

InnerNet's mail client. Addresses use the format name@domain.tld — these are in-mail addresses, not regular email. They only work within InnerNet.

Create an account

Your domain must have MX set to mail.host. Then go to mail.party, enter your desired address and a password, and click Create.

Send & receive

Log in with your address and password. Compose sends to any in-mail address. Received mail appears in your inbox. Session persists until you sign out.

bankly.lbc

View your LUCKS balance and transfer LUCKS to other users. LUCKS are InnerNet's currency — used for domain registration and anything else the community decides to price.

Transfers

Enter a username and amount. Transfers are instant and irreversible. You can't transfer to yourself or send more than your balance.

Getting LUCKS

LUCKS can be added by @luciano via the admin API. They can also be earned by providing services to other users on InnerNet.

reviews.inn

Leave and read reviews for any InnerNet domain. Built on the KV system. Requires an InnerNet account to submit a review.

Each user can leave one review per domain. Reviews include a star rating (1–5) and a text body.

KV Storage

Every project gets a key-value store. Use it to persist data across page loads — reviews, counters, user-generated content, anything JSON-serializable.

Limits

PlanStorage
Default100 KB per project
Extended (owner-assigned)1 MB per project

Check your usage at GET /kv/:projectId/size. If you need more than 1 MB, you'll need your own backend.

Reading data (public)

// No auth required — anyone can read
fetch("https://own-net.vercel.app/kv/PROJECT_ID/my-key")
  .then(r => r.json())
  .then(d => JSON.parse(d.value))

Writing data

Writes go through the Env Proxy — direct POST to /kv requires auth. See the next section.

Env Variables

Store secrets in the backend, not in your HTML. Env vars are tied to a project and only readable server-side. The name is visible in your code; the value never leaves the server.

Create a variable

From the browser console while logged in to InnerNet:

fetch("https://own-net.vercel.app/projects/PROJECT_ID/env", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer " + localStorage.getItem("inn_token")
  },
  body: JSON.stringify({ name: "MY_KEY", value: "my-secret-value" })
})
localStorage is blocked inside the InnerNet browser iframe. Run this from a direct tab at innernet.qzz.io or own-net.vercel.app.

List variables (names only)

GET /projects/:id/env  // returns names, never values

Delete a variable

DELETE /projects/:id/env/:name

Env Proxy

The env proxy lets your static HTML make authenticated requests without exposing secrets. You send the variable name in a header; the backend looks up the value itself and performs the operation.

Write to KV via env proxy

// In your HTML — the value of MY_KEY never appears here
fetch(`https://own-net.vercel.app/env-proxy/PROJECT_ID/kv/my-key`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-env": "MY_KEY"  // name only
  },
  body: JSON.stringify({ value: myData })
})

How it works

The backend receives x-env: MY_KEY, looks up MY_KEY in the DB for that project, verifies it exists, then performs the KV write internally. The actual key value is never sent over the network.

Anyone who knows the variable name can trigger the proxy — but they can only write to your project's KV. They can't read the variable value or use it anywhere else.

Projects

Projects let you host multi-file sites with HTML, CSS, JS, and more. Each project gets a URL at own-net.vercel.app/projects/UUID/.

Create a project

POST /projects  { name: "my-project" }

Upload files

POST /projects/:id/files  { path: "index.html", html: "..." }
POST /projects/:id/files  { path: "about.html", html: "..." }
POST /projects/:id/files  { path: "css/style.css", html: "..." }

You dont actually have to use POST or console, just enter innernet.qzz.io/host

Files are gzip-compressed in storage. The path field is relative — use index.html for the root.

Link to a domain

Set your domain's CNAME to https://own-net.vercel.app/projects/UUID/ in getaname.lbc.

API — Auth

POST/auth/register
Create a new account. Body: { username, password }. Returns { token, username, lucks }.
POST/auth/login
Log in. Body: { username, password }. Returns { token, username, lucks }.
GET/meauth
Get current user. Returns { username, lucks }.

API — Domains

POST/domains/registerauth
Register a domain. Body: { domain }. Deducts 100 LUCKS.
GET/domains/mineauth
List all domains owned by the current user.
GET/domains/:domain
Get info for a specific domain.
POST/domains/cnameauth
Set CNAME. Body: { domain, cname }.
POST/domains/mxauth
Set MX record. Body: { domain, mx }.
GET/resolve/:domain
Resolve a domain — returns owner, CNAME, MX.
GET/search?q=
Search domains by name. Returns up to 50 results scored by relevance.
POST/domains/subauth
Create a subdomain. Body: { domain, subdomain, cname?, mx? }. Parent domain must be yours.
GET/domains/:domain/subs
List all subdomains of a domain.
PUT/domains/subauth
Update subdomain CNAME or MX. Body: { domain, subdomain, cname?, mx? }.
DELETE/domains/subauth
Delete a subdomain. Body: { domain, subdomain }.

API — Mail

POST/mail/createauth
Create a mail account. Body: { address, password }. Domain must have MX set and be owned by you.
POST/mail/:domain/:user/send
Send mail. Body: { password, to, subject, body }.
POST/mail/:domain/:user/inbox
Get inbox. Body: { password }. Returns array of mail objects.

API — LUCKS

POST/lucks/addx-api-key
Add LUCKS to a user. Admin only — requires x-api-key header. Body: { username, amount }.
POST/lucks/transferauth
Transfer LUCKS to another user. Body: { to, amount }.

API — KV

GET/kv/:project/:key
Read a value. Public. Returns { key, value } where value is a JSON string.
POST/kv/:project/:keyauth
Write a value. Requires auth as project owner. Body: { value }.
DELETE/kv/:project/:keyauth
Delete a value. Requires auth as project owner.
GET/kv/:project/size
Check storage usage. Returns { used, limit, unit } in bytes.
POST/env-proxy/:project/kv/:key
Write via env proxy. Header: x-env: VAR_NAME. The backend validates the var exists for this project. Body: { value }.

API — Projects

POST/projectsauth
Create a project. Body: { name }. Returns project with UUID.
GET/projectsauth
List your projects.
POST/projects/:id/filesauth
Upload or overwrite a file. Body: { path, html }.
GET/projects/:id/filesauth
List all files in a project.
GET/projects/:id/*
Serve a project file publicly. Falls back to index.html for paths without extension.
DELETE/projects/:idauth
Delete a project and all its files.
DELETE/projects/:id/files/:pathauth
Delete a specific file from a project.
POST/projects/:id/envauth
Create or update an env variable. Body: { name, value }.
GET/projects/:id/envauth
List env variable names (values never returned).
DELETE/projects/:id/env/:nameauth
Delete an env variable.
